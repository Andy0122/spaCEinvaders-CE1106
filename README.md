## 🚀 Arquitectura del Proyecto
Este repositorio contiene un monorepo dividido en tres partes:
1. **Servidor (Java):** Maneja la lógica del juego y la concurrencia mediante Sockets (Paradigma Orientado a Objetos).
2. **Cliente (C):** Interfaz gráfica para los jugadores y espectadores (Paradigma Imperativo).
3. **Controlador Hardware:** Código en C para enviar comandos mediante la Raspberry Pi Pico.
